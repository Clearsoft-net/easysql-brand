Border Radius System

Derived from the official 72×72 px monogram tile (rx=16px), establishing the ~22.2% squircle ratio for brand containers and a cohesive UI scale for applications.

Brand Tile Squircle Ratio (22.2%)
App icons, squircle avatars, and brand containers follow:
R ≈ Size × 0.222 (72px → 16px · 16px → 3.5px)
Extra Small (xs) 4px
4px radius

SQL data types (VARCHAR, INT, FK), compact tooltips, tree view badges, sub-nodes.

Small (sm) 6px · 8px
6–8px radius

Form inputs, select dropdowns, secondary action buttons, context menus, list selectors.

Medium (md) 10px · 12px
10–12px radius

Primary buttons (CTAs), query editors, SQL code blocks, filter dialogs, inner card surfaces.

Large (lg) · Brand Signature 16px
16px radius

Main dashboard cards, modals, side-drawers. Directly mirrors the 16px curvature of the official monogram.

Extra Large (xl) 24px
24px radius

Hero feature panels, marketing callouts, elevated onboarding containers.

Pill / Full 9999px
Pill / Full

Status indicators (Connected, Synced), category tags, floating action chips, circular buttons.

:root {
  --radius-xs: 4px;      /* SQL type badges, tree nodes */
  --radius-sm: 8px;      /* Form inputs, select dropdowns, secondary buttons */
  --radius-md: 12px;     /* Primary CTAs, query editors, code blocks */
  --radius-lg: 16px;     /* Dashboard cards, modals (brand signature) */
  --radius-xl: 24px;     /* Hero feature panels, callouts */
  --radius-full: 9999px; /* Status pills, chips */
  --tile-ratio: 0.222;   /* Squircle: rx = size * 0.222 */
}

Standards

Brand Usage Guidelines

Preserve brand integrity by maintaining exact colors, padding, and proportions.

Do’s

  • ✓ Use dark variations (01, 03, 05, 07) on dark blue, petroleum, and black backgrounds.
  • ✓ Use light variations (02, 04, 06, 08) on light gray, white, and paper backgrounds.
  • ✓ Keep "Easy" in Space Grotesk and "SQL" in Geist; "SQL" stays #F97316.
  • ✓ Use the monochrome lockups for one-color, small, or light-background reproduction.
  • ✓ Use the 16/24 px small icon cut below 32 px.
  • ✓ Maintain minimum clear space equal to the height of the wordmark letters around the logo.
  • ✓ Always spell the product name as EasySQL (CamelCase, no spaces).

Don’ts

  • ✗ Do not stretch, skew, or distort the logo aspect ratio.
  • ✗ Do not alter the orange-to-pink gradient (#F97316 → #F472B6).
  • ✗ Do not add drop shadows, outer glows, or bevels to the monogram.
  • ✗ Do not separate "Easy" and "SQL" with a dot, slash, or space.
  • ✗ Do not invert the "Easy"/"SQL" colors or use the orange SQL at small sizes on white.
  • ✗ Do not use the standard icon at 16/24 px.
  • ✗ Do not render "Easy SQL" with a space or all-lowercase.
